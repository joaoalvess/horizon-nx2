# Reports

One file per subagent run, written by the subagent that ran and never edited afterwards: `<YYYYMMDD-HHMM>-<item>-<role>.md`. For example, `20261105-0130-C3-review.md`, `20261105-0100-C3-impl.md` or `20261105-0700-S0-capture.md`.

`<item>` is a catalog ID or a stage. `<role>` is `impl`, `review`, `capture`, `search` or `final-review`.

The main thread links the reports from the catalog's State column and from the night file.
