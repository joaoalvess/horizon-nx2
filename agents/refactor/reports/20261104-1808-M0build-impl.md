## What the diff does

1. `dm/host/Makefile` compiles each host source into `gen/<id>/obj/host/<file>.o` or `gen/<id>/obj/gfx/<path>.o`, with the same flags as the old single command plus `-MMD -MP`. It drops the `-Wl,` option from the compile, since that only matters at the link, and makes the profile, revision and shader headers order-only prerequisites. It links with the old `CFLAGS`, `-Wl,-object_path_lto,gen/<id>/obj/lto` and `dsymutil`, the two things the clang driver did implicitly. The hand-written header list and `GFX_H` go away, `-include` reads the `.d` files, and a phony `host_obj` builds the objects alone (for the NSP script patch below).
2. `DM_HOST_REV` is no longer a `-D` but `gen/<id>/host_rev.h`, rewritten only when `git describe --always --dirty` changes. `stream_mac.m` includes it under `__has_include`, so the `"unknown"` fallback still serves `t_stream`/`t_stream_sock` and lint.
3. `gen_build.py` and `compile_check.py` put the host's own commands first by output path (`dmhost` or `gen/*/obj/`) and stop repeating `-D`. `project.yml` gets project-level `settings.configs.Release` `GCC_OPTIMIZATION_LEVEL: 2` and `LLVM_LTO: YES_THIN` (D5). `docs/development.md` adds `-j8` to step 4 and one note on objects and `host_rev.h`.
