Branch `refactor`, not committed. The R1 diff in `dm/gfx/tests/nvn_replay.m` was not touched. The binaries built from the tree contain it.

## Files changed

## What the diff does

1. `cap_pf_block` handles a compressed Metal format that the plain and BC checks miss by finding the NVN format the layer makes it from (`fmt_compressed` and `nvn_fmt_to_mtl` over 1..`NVN_FORMAT_BGRA8_SRGB`). It takes that format's block from `nvn_fmt_bpb`. This uses the same tables the upload path writes those textures with, and adds no new table.
2. As a result, the 28 ASTC formats (LDR and sRGB, 14 sizes each) are read back into TPIX chunks. Nothing else changes: the file format (`CAP_VERSION` 1), the replayer, and plain or BC formats behave as before.
3. The tests pin every format that maps to Metal, and run a DK-shaped case: an ASTC 8x8 sRGB copy destination written in frame 1 is read into the presented target inside one frame-2 submission.

## Verification of the search report (before any change)

Every claim checked held:
- **Only gate:** `cap_pf_block` is the only function that decides whether a format can be read back. Its callers are `cap_tex_readback` (`nvn_capture.inc:237`) and the gate in `cap_tex_read` (`:276`). `cap_digest` uses `cap_pf_bpp` only.
- **Replayer:** `fill_tex` (`nvn_replay.m:150-169`) uses only the captured `row`/`img`/`bytes`.
- **Format paths:** `tex_desc` takes every format from `nvn_fmt_to_mtl` and returns nil for the `N` entries.
- **Helpers in scope:** `fmt_compressed` (`nvn_mtl.m:1714`) and `fmt_depth` (`:1715`) are visible in `nvn_capture.inc`, which is included at `nvn_mtl.m:13109`. So are `nvn_fmt_to_mtl` (through `nvn_mtl.m:22`) and `nvn_fmt_bpb` (through `nvn_obj.h` → `nvn_tex.h`).
- **No Metal-keyed table:** the only Metal-keyed block helper, `mtl_fmt_block` (`nvn_mtl.m:3910`), is a yes/no predicate with no dimensions.
- **Replay never calls it:** the replayer never runs the capture hooks (no `nvn_cap_submit` or `nvn_cap_present` in `nvn_replay.m`). So `cap_pf_block` does not run during a replay.
