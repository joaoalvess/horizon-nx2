## What the diff does

1. `facts.py` dumps nvn_mtl.m's AST with the host's compile line (`make -n` through `lint_c.py`) and reads every top-level declaration of nvn_mtl.m, nvn_rec.h and the three `.inc` files (line range, columns, storage), each function's calls, function references and global accesses (R/W/P, blocks counted for their function), each global's type; `modmap.py` turns them and the tables into the map: the module of every line, the edges, the layering check, splits and stale rows.
2. `move.py` moves one module verbatim (in compiler order, `.inc` lines at their `#include`) into `mtl_<m>.m` / `.h`, with linkage edits, same-line declaration splits, generated header declarations, the header included by nvn_mtl.m and the module added to the unity file; it refuses a stale map or a module that still needs code left behind.
3. `movecheck.py` checks a patch or commit: in a move, the removed lines in compiler order are the module's lines, in order in each of its two files, apart from linkage edits, splits and the generated lines, each checked against what the move tool writes; in a cut, the multiset of removed lines equals the added ones apart from the listed edits. `callcheck.py` compares the hot functions' call counts per callee in two hosts against the section 6 / D8 allowlist (Revision 1).
