### Compiler warnings

- The Mac host (`dm/host/Makefile:18`) and `dm/gfx/tests/Makefile:14` build `nvn_mtl.m` with `-Wall`. That includes `-Wuninitialized` / `-Wsometimes-uninitialized`, but not `-Wconditional-uninitialized`.
- Clang's `-Wsometimes-uninitialized` fires only when some branch edge leads unconditionally to the use without setting the variable. Here the use at `:830` sits behind its own `if (n > 1)`, so the false edge of `:817` reaches it only through another test. Clang classifies that as "may be uninitialized", which only `-Wconditional-uninitialized` reports (it is in `-Weverything`, not `-Wall`/`-Wextra`).
- The iOS build sets `GCC_WARN_INHIBIT_ALL_WARNINGS: YES` (`dm/ios/project.yml:84`), so it passes `-w`.
- The only `-Werror` compile of this file's code, `dm/gfx/tests/test_geometry_split.py:100`, extracts only `geo_split`.
- So no build in the repository warns. Under `-O2`/ThinLTO, folding the two identical tests is legal, because there is no UB: the variables are never read when unset.
