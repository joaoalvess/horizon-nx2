## What the diff does

1. Host, gfx tests and host tests at `-O2` with ThinLTO; the host and the `$(CFLAGS)` gfx tests link with `-export_dynamic`, so exported symbols stay BASE's.
2. Every function reading `__builtin_return_address` / `__builtin_frame_address` is `noinline`. The attribute precedes the macro invocation and attaches to the macro's forward declaration.
3. The big-stack return path stays in the linker atom that falls through into it.

## Did not hold

1. **ThinLTO hung every big-stack call; root cause fixed.** `t_present_crop` spun at 100 % CPU (guard stall, `events.tsv` 03:55:18); `sample`: a loop at `dm_bigstack_enter` +56..92 → `dm_stream_take` +4 (`ret`). Clang marks Mach-O objects `.subsections_via_symbols`, so each symbol starts an atom the linker may move or dead-strip. In `hle_bigstack.c`'s module asm, `_dm_bigstack_enter` falls through `blr x16` into the global label `_dm_bigstack_ret`, and `cbz x17, 1f` branches into that second atom. Without LTO the linker kept input order; with ThinLTO the `_dm_bigstack_ret` atom moved 0x20 bytes before `_dm_bigstack_enter` in the host (after `blr` the CPU ran into `_h_gs_check: ret`), and was dead-stripped in tests that never reference it. Impact: every `HLE_FORCE_BIG`, the 342 NVN big-stack functions, `VKB` and `GLB`; any boot would have hung. Fix: `.alt_entry _dm_bigstack_ret` (this symbol does not start an atom); the same for `_call_on_site` in `t_bigstack.c`. Other asm checked: the stubs in `hle.h`, `hle_vk.m`, `hle_gl.m` each end in a branch; `gl_stubs` is one 0x8000-byte atom; no `.S` file uses `.subsections_via_symbols`.
2. **LTO internalized main-program globals; `t_ub` failed** (`DM_NVN_UB: global variable not found: g_t_ub_var`). `ub_var` (`nvn_mtl.m` 1430-1437) finds unregistered `@set:` switches with `dlsym(RTLD_DEFAULT, …)` on the Mac by design; without `-export_dynamic`, LTO may inline and remove global functions (`man ld`). Fix: `-Wl,-export_dynamic` in the host and gfx-test `CFLAGS`; exports back to 2056; `t_ub` passes. Cost: LTO cannot drop or internalize non-static globals; cross-module inlining is unaffected. Not added to `dm/host/tests`. Alternative: drop the flag, accept that `@set` finds only registered switches (as on iOS), and change `t_ub`.
3. ThinLTO does not import functions that reference local `used` statics (the HLE / NVN / VK / GL tables) from those files; inlining within each file is unaffected.
